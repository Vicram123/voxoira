    01

    AI engine

    Choose the service that will answer your questions.

    • Browser AI — no API key; runs on supported browsers.
    • OpenAI-compatible — OpenAI, Groq, OpenRouter, Ollama-compatible services, etc.
    • Anthropic — Claude API.
    • Google Gemini — Gemini API.
    AI engine
    Browser AI ⌄
    Choose your provider

    If you do not have an API key yet, start with Browser AI if your browser supports it.

    02

    API key

    This is the secret credential supplied by your AI provider.

    • Create an API key in the provider's developer/AI dashboard.
    • Copy the complete key without extra spaces.
    • Paste it into API key.
    • If you see a 401/403 error, check the key, billing/quota, and permissions.
    API key
    ••••••••••••••••
    Stored locally in this browser

    Never post your API key in screenshots, GitHub, or public HTML.

    03

    Endpoint

    The endpoint is the web address where Voxoira sends the AI request.

    • For OpenAI, use the chat completions endpoint shown by the app.
    • For compatible providers, use the provider's OpenAI-compatible endpoint.
    • Anthropic and Gemini use their provider-specific endpoints automatically in this app.
    Endpoint
    https://api.provider.com/…
    Request destination

    If you get 404, CORS, or “failed to fetch”, the endpoint or provider access may be the problem.

    04

    Model

    The model is the specific AI you want the selected engine to run.

    • Enter a model name that exists for your provider and account.
    • Use the exact spelling/capitalization shown in the provider dashboard.
    • A 400 error often means the model name or request format is wrong.
    Model
    gpt-4o-mini
    Exact provider model name

    If your key works but you see “model not found”, check the model name first.

    VOXOIRA · ABOUT

    Voxoira

    A browser-based workspace for voice dictation, translation, and AI-assisted text workflows.

    What Voxoira does

    Voxoira helps you turn speech into editable text, translate spoken or written content, and work with text using an AI assistant. The app is designed to keep the main workflow simple: speak, review, edit, translate, and ask AI.

    Dictate

    Use browser speech recognition to create editable notes and documents. Voxoira includes language selection, microphone controls, formatting tools, autosave, copy, and download options.

    Translate

    Speak into the translation workspace, select languages, review the original and translated text, and use the available copy, download, and speech controls.

    Ask AI

    Ask AI can work with selected Voxoira text. Depending on your setup and browser support, it can use Browser AI or a third-party provider such as an OpenAI-compatible endpoint, Anthropic, or Gemini.

    Built for practical use

    Voxoira is intended for everyday writing, notes, translation assistance, and text exploration. AI and speech results should always be reviewed before being used for important decisions.

    Transparency: Voxoira is not affiliated with Google, OpenAI, Anthropic, or Google Gemini. Third-party provider names are referenced only to explain optional integrations.

    VOXOIRA · HELP

    FAQ & Help

    Answers to common questions about Voxoira's main features and AI connections.

    How do I start dictation?

    Open Dictate, choose your language, allow microphone access when your browser asks, and start the microphone. Interim speech is shown live while you speak.

    Why isn't my microphone working?

    Check that the browser has microphone permission, the correct input device is selected, and another application is not blocking the microphone. HTTPS is recommended for production deployment.

    How does Translate work?

    Choose the source and target languages, start speech input, review the original text, and use the translation controls to review or speak the result.

    Why does Ask AI need an API key?

    External AI providers generally require authentication. Browser AI may work without a key when supported by the browser. Never publish a private provider key in client-side source code.

    What does “401 / 403” mean?

    Usually the provider rejected the credential or account request. Check the API key, account permissions, billing/quota, and provider access.

    What does “Failed to fetch” mean?

    It can indicate a network problem, incorrect endpoint, provider outage, or browser CORS restrictions. Verify the endpoint and provider documentation.

    Can I rely on AI output?

    No. AI responses can be incorrect or incomplete. Review generated text before using it for legal, medical, financial, safety, or other high-impact decisions.

    How do I request privacy help?

    Email the site's privacy/support address listed on the Contact page. Do not include passwords or API keys in your message.
