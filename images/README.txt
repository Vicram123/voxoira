Voxoira website image assets

Files:
- dictation.webp       -> Dictation / voice-to-text feature
- translation.webp     -> Translation feature
- ask-ai.webp          -> Ask AI feature
- footer-banner.webp   -> Footer promotional banner

How to use:
1. Extract the images folder contents.
2. Put the files in an `images` folder beside your `index.html`.
3. Use paths such as `images/dictation.webp` in your HTML.

These are cropped from one generated composite illustration, so inspect each crop before publishing and adjust crop/position if needed.
